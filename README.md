# DEE---Trabajo-Final
Trabajo final de la asignatua de Datos Espaciales y Espaciotemporales, del tercer año del grado de Business Intelligence &amp; Analytics de la Universitat de València

### ARCHIVOS DISPONIBLES

- Data.zip, dentro de la carpeta data: donde se encuentran todos los datasets necesarios para la ejecución y renderizado correcto del código
- Codificaciones.R: Script utilizado para la geocodificación de Expendurías de Tabaco y Timbre y PVRs. También se encuentra en el ANEXO I del archivo ANEXOS.pdf
- ANEXOS.pdf: Documento con los ANEXOS I, II, III, IV y V.
- ANEXOS.Rmd: Script utiizado para la renderización de ANEXOS.pdf
- PROYECTO_FINAL.pdf: Documento final de la asignatura
- PROYECTO_FINAL.Rmd: Script utilizado para la renderización de PROYECTO_FINAL.pdf
